## 📚 Idea/Concepto 


La Latencia es una medida de rendimiento (Performance) que se define como el tiempo transcurrido o de retraso para que un mensaje o paquete de datos se transfiera entre el cliente y el servidor. Cuantifica "qué tan rápido" el sistema está disponible para responder a una solicitud. La latencia total es la suma de dos componentes: la latencia de red y la latencia de procesamiento en el servidor. En sistemas de bases de datos distribuidas con replicación, existe un trade-off fundamental entre la consistencia y la Latencia. Existe además una relación inversa entre latencia y throughput, es decir, usualmente mejorar una require que se degrade la otra.
