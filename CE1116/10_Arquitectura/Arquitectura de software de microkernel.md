## 📚 Idea/Concepto 


La arquitectura de microkernel es un estilo de arquitectura monolítica simple que tiene dos componentes, el sistema central y uno o más componentes plug-in. El sistema central tiene la funcionalidad mínima para ejecutar el sistema y los componentes plug-in tienen como propósito aislar el código altamente volátil y procesamiento especializado, para el descubrimiento y acceso de los módulos se hace el registro de estos plug-ins, además de que exponen un contrato para que el sistema los contacte. Mediante esta división se tiene extensibilidad, adaptabilidad y un mejor mantenimiento y usabilidad del sistema.
